# AGENTS.md — rules for AI coding tools

This file is the project memory for AI tools that work on Space Fractions later.

## Package layout

- `spacefractions/game` — game state machine (`Game`, `GameState`, `AnswerResult`)
- `spacefractions/question` — `Question` model, `QuestionType` and the question factory
- `spacefractions/user` — local player identity (`User`, `UserService`)
- `spacefractions/admin` — question management (`Admin`, `AdminService`)
- `spacefractions/storage` — SQLite repositories (`Database`, `QuestionRepository`, `ScoreRepository`)
- `spacefractions/ui` — Tkinter screens (`App` and screen classes)

## Layering rule

Domain packages `game`, `question`, `user`, `admin` and `storage` must **not** import
`spacefractions.ui`. The UI may import domain and storage packages. Storage must use `?`
parameters only — never build SQL with f-strings, `format()` or `+`.

## Language and imports

- Python 3.11, standard library only. No web frameworks, no servers.
- Fraction maths uses `fractions.Fraction` (no floating point for correctness).
- Never use `eval`, `exec`, `os.system`, `subprocess`, `pickle.loads` or `__import__`.

## Header convention

Every non-empty `.py` file starts with:

```
# Generated by SpaceFractions Code Agent (model: deepseek-v4-pro). AI-generated code - review before production use.
# Traces: <requirement ids implemented here, e.g. FR-1, ASR-1>
```

Keep the first line exactly; update the `# Traces:` line to reflect the requirement ids
implemented in that file.

## Running

- Run the game: `python main.py`
- Run tests: `python -m unittest discover -s tests`
- Tests must be unittest-based and headless: never create `tk.Tk` and never call `mainloop()`.

## Data

The SQLite database file `spacefractions.db` lives next to `main.py`. The schema is owned by
`spacefractions/storage/database.py` (tables `questions` and `scores`).
